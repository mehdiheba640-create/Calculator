# 🧮 Simple Calculator

A clean, minimalist, and responsive web-based calculator designed with iOS-inspired circular buttons, built using vanilla HTML5, CSS3, and JavaScript.

🔗 Live Demo: [mehdiheba640-create.github.io/Calculator](https://mehdiheba640-create.github.io/Calculator/)

---

## ✨ Features

- Basic Arithmetic Operations: Supports addition (+), subtraction (-), multiplication (*), and division (/).
- Dynamic Expression Input: Sequential entry of digits and decimal numbers directly onto the digital display screen.
- Calculation Evaluation: Evaluates expressions upon clicking the equals (=) button.
- Error Handling: Catches invalid syntax and displays a clear ERROR state rather than breaking the application.
- Clear Display: Resets input instantly with a dedicated clear (C) button.
- Modern Dark Interface: Dark theme UI styled with custom CSS Grid layout, hover transitions, and active tactile feedback states.

---

## 🛠 Built With

- HTML5: Semantic keypad structure, container layout, and readonly display input.
- CSS3: CSS Grid (repeat(4, 1fr)), circular buttons, HSL color palettes, and hover/active animations.
- JavaScript (ES6): Input concatenations, display state management, and calculation execution.
- GitHub Pages: Static site hosting and deployment.
